# DRV-02: Один ключ провайдера на контракт

Тип: внешнее ограничение.

Провайдер выдаёт по контракту ключ доступа (или ограниченный набор ключей) и тарифицирует потребление на уровне контракта. Внутренняя структура организации провайдеру неизвестна: по его данным невозможно узнать, какая ИС или какое подразделение выполнили запросы.

Это ограничение не зависит от организации: изменить модель выдачи ключей провайдера она не может. Значит, учёт в разрезе внутренних потребителей может вести только сама организация, на своей стороне, в точке, через которую проходят все запросы. Иначе — распределение затрат и контроль бюджетов остаются оценочными.
