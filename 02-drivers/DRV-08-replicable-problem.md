# DRV-08: Типовая проблема многих организаций

Тип: причина изменений (драйвер вендора).

Ситуация «несколько независимых ИС потребляют одного внешнего провайдера по общему контракту» не специфична для отрасли: она возникает в любой организации с несколькими подразделениями, каждое из которых эксплуатирует свою ИС. Решения, которые организации строят сами, обычно закрывают одну грань проблемы (например, только кэш или только учёт) и не переносятся между организациями.

Это делает рынок для коробочного продукта, но только при условии, что продукт подключается к новым провайдерам и потребителям конфигурацией, без доработки под каждого покупателя.
