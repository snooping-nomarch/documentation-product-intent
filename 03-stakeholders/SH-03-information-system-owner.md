# SH-03: Владелец и команда информационной системы

Тип: основной пользователь (через программный интерфейс).

Владелец, разработчики и эксплуатация ИС, которая обращается к внешнему провайдеру через продукт по своему внутреннему ключу. Для них продукт — посредник на критическом пути их бизнес-операций.

## Интересы и требования

- Подключение к провайдеру через продукт без переделки логики ИС: работа «как с провайдером напрямую».
- Предсказуемость: заранее известно, что произойдёт при исчерпании лимита, и ИС узнаёт об этом явно.
- Работа ИС при недоступности провайдера там, где это допустимо, с явной пометкой устаревших данных.
- Возможность разобрать, что произошло с конкретным запросом.
- Минимальная задержка, которую добавляет продукт.
