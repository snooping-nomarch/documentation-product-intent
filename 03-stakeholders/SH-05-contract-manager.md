# SH-05: Ответственный за договор с провайдером

Тип: владелец процесса (договорная работа и сверка).

Ведёт контракт с внешним провайдером: условия тарификации, объёмы, продление, сверки и подписание актов. Системой пользуется через отчёты о потреблении за период.

## Интересы и требования

- Потребление за период, посчитанное по правилам тарификации провайдера, — собственный аргумент при сверке.
- Объяснимость расхождений с актом провайдера.
- История потребления для переговоров об объёме и условиях следующего контракта.
