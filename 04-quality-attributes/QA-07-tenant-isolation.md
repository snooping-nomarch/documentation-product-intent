# QA-07: Изоляция организаций-покупателей

В SaaS одна инсталляция продукта обслуживает несколько организаций. Каждая из них приносит свои контракты, ключи провайдеров, внутренние ключи, данные в кэше и учёт.

## Обещание

- Данные, настройки, кэш и учёт одной организации недоступны другой ни через продукт, ни через его отчёты.
- Нагрузка, лимиты и сбои одной организации не влияют на обслуживание другой.
- Ответ провайдера, полученный по контракту одной организации, не отдаётся из кэша другой организации.
- On-premise инсталляция обслуживает одну организацию той же моделью продукта.
