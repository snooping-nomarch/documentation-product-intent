# CTX-01: Провайдеры и контракты

Описание [ограниченного контекста][BOUNDED-CONTEXT-TERM] `CTX-01` в [замысле продукта][PRODUCT-INTENT-TERM].

Контекст описывает внешний мир со стороны организации: каких провайдеров она потребляет, по каким контрактам, с какими ключами провайдера и по каким правилам провайдер тарифицирует обращения. Контекст заканчивается там, где начинаются внутренние потребители организации ([CTX-02](../CTX-02-consumers-and-limits/readme.md)) и обработка конкретных обращений ([CTX-03](../CTX-03-proxying-and-caching/readme.md)).

## Единый язык

- **Провайдер** — внешний поставщик данных или сервиса с REST-интерфейсом, к которому обращаются ИС организации.
- **Контракт** — договор организации с провайдером: период действия, объём и правила тарификации. У провайдера может быть несколько контрактов одной организации.
- **Ключ провайдера** — учётные данные, выданные провайдером по контракту. У контракта может быть несколько ключей (пул). Ключ провайдера никогда не покидает продукт.
- **Эндпоинт** — класс обращений к провайдеру с одинаковыми правилами тарификации и кэширования.
- **Единица потребления** — то, в чём провайдер тарифицирует потребление: одно обращение или вес эндпоинта. Способ задаётся для провайдера.
- **Правила тарификации** — какие исходы обращения (успех, ошибки клиента и провайдера, повторы, таймауты) провайдер тарифицирует и сколько единиц потребления списывает за каждый.

## Границы

### Входит

- Реестр провайдеров, их контрактов и ключей провайдера.
- Правила тарификации и единица потребления провайдера.
- Ограничения провайдера, действующие на весь контракт: частота и параллельность обращений.

### Не входит

- Внутренние ключи, лимиты потребителей и структура подразделений — [CTX-02](../CTX-02-consumers-and-limits/readme.md).
- Выполнение обращений и кэш — [CTX-03](../CTX-03-proxying-and-caching/readme.md).
- Подсчёт фактического потребления — [CTX-04](../CTX-04-consumption-metering/readme.md).
- Цены в деньгах и финансовые условия контракта — вне продукта.

## Capability в этом контексте

## Интеграция

- Передаёт [CTX-03](../CTX-03-proxying-and-caching/readme.md) сведения о провайдере, контракте и ключах провайдера для выполнения обращений.
- Передаёт [CTX-04](../CTX-04-consumption-metering/readme.md) правила тарификации для расчёта единиц потребления.
- Передаёт [CTX-05](../CTX-05-settlement-and-allocation/readme.md) контракт и его период для сверки.
