# CTX-02: Потребители и лимиты

Описание [ограниченного контекста][BOUNDED-CONTEXT-TERM] `CTX-02` в [замысле продукта][PRODUCT-INTENT-TERM].

Контекст описывает внутреннюю сторону организации: кто из её информационных систем потребляет провайдеров, по каким внутренним ключам, к каким подразделениям они относятся и сколько каждому ключу разрешено потребить. Контекст заканчивается там, где начинается внешний мир провайдеров ([CTX-01](../CTX-01-providers-and-contracts/readme.md)) и фактический подсчёт потребления ([CTX-04](../CTX-04-consumption-metering/readme.md)).

## Единый язык

- **Потребитель** — информационная система организации, которая обращается к провайдерам через продукт.
- **Внутренний ключ** — учётные данные, выданные продуктом потребителю. Единица авторизации, учёта и лимитирования: всё потребление атрибутируется внутреннему ключу.
- **Подразделение** — узел дерева организационной структуры произвольной глубины. Группирует внутренние ключи для отчётности. Лимитов не имеет.
- **Лимит** — максимальный объём единиц потребления, который внутренний ключ может потребить у провайдера за период.
- **Политика исчерпания** — что происходит, когда лимит исчерпан: жёсткий отказ, мягкий лимит с оповещением или овердрафт.
- **Остаток лимита** — разница между лимитом и потреблением по ключу в текущем периоде.

Лимиты задаются только на внутренний ключ. По иерархии подразделений лимиты не задаются и не суммируются: бюджет подразделения — это совокупность лимитов его ключей, которую формирует организация.

## Границы

### Входит

- Выпуск, отзыв и права внутренних ключей.
- Дерево подразделений и отнесение ключей к подразделениям.
- Лимиты внутренних ключей, политики исчерпания и решение «допустимо ли обращение по лимиту».

### Не входит

- Провайдеры, контракты, ключи провайдера — [CTX-01](../CTX-01-providers-and-contracts/readme.md).
- Подсчёт потребления — [CTX-04](../CTX-04-consumption-metering/readme.md); этот контекст использует его итоги для остатка лимита.
- Отчёты о распределении — [CTX-05](../CTX-05-settlement-and-allocation/readme.md).
- Учётные записи пользователей продукта и их роли.

## Capability в этом контексте

Перечень — в [index.md](index.md): `CAP02-01`, `CAP02-02`, `CAP02-03`.

## Интеграция

- Предоставляет [CTX-03](../CTX-03-proxying-and-caching/readme.md) проверку внутреннего ключа и решение по лимиту для каждого обращения.
- Получает от [CTX-04](../CTX-04-consumption-metering/readme.md) потребление по ключу в текущем периоде.
- Предоставляет [CTX-04](../CTX-04-consumption-metering/readme.md) и [CTX-05](../CTX-05-settlement-and-allocation/readme.md) отнесение ключей к подразделениям на момент потребления.
