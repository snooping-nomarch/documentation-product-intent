# CTX-03: Проксирование и кэширование

Описание [ограниченного контекста][BOUNDED-CONTEXT-TERM] `CTX-03` в [замысле продукта][PRODUCT-INTENT-TERM].

Контекст описывает путь отдельного обращения информационной системы: от входа в продукт до ответа — из кэша, от провайдера или отказом. Здесь принимается решение, что делать с обращением; правила для этого решения приходят из [CTX-01](../CTX-01-providers-and-contracts/readme.md) и [CTX-02](../CTX-02-consumers-and-limits/readme.md), а факт обращения передаётся в [CTX-04](../CTX-04-consumption-metering/readme.md).

## Единый язык

- **Обращение** — запрос ИС к провайдеру, поступивший в продукт по внутреннему ключу.
- **Запрос к провайдеру** — обращение, которое продукт передал провайдеру от имени организации по ключу провайдера.
- **Ответ из кэша** — ответ на обращение, данный продуктом без запроса к провайдеру.
- **Политика кэширования** — правила для эндпоинта: какие обращения считаются одинаковыми, сколько ответ остаётся актуальным, допустима ли отдача устаревшего ответа.
- **Устаревший ответ** — ответ из кэша, срок актуальности которого истёк; отдаётся только при недоступности провайдера, если это разрешает политика, и всегда с явной пометкой.
- **Режим деградации** — обслуживание обращений при недоступности провайдера.

## Границы

### Входит

- Приём обращения, проверка внутреннего ключа и решения по лимиту, передача провайдеру по ключу провайдера, возврат ответа.
- Общий для инсталляции кэш ответов и политики кэширования эндпоинтов.
- Обслуживание обращений при недоступности провайдера.

### Не входит

- Выдача ключей и лимиты — [CTX-02](../CTX-02-consumers-and-limits/readme.md).
- Подсчёт потребления — [CTX-04](../CTX-04-consumption-metering/readme.md).
- Наблюдение за состоянием провайдеров и трассы — [CTX-06](../CTX-06-observability/readme.md).
- Преобразование данных провайдера, объединение ответов нескольких провайдеров.

## Capability в этом контексте

Перечень — в [index.md](index.md): `CAP03-01`, `CAP03-02`, `CAP03-03`.

## Интеграция

- Получает от [CTX-01](../CTX-01-providers-and-contracts/readme.md) провайдера, контракт, ключ провайдера и эндпоинт обращения.
- Получает от [CTX-02](../CTX-02-consumers-and-limits/readme.md) проверку внутреннего ключа и решение по лимиту.
- Передаёт в [CTX-04](../CTX-04-consumption-metering/readme.md) факт каждого обращения с его исходом.
- Передаёт в [CTX-06](../CTX-06-observability/readme.md) сведения о ходе обращения и ответах провайдера.
