# CTX-04: Учёт потребления

Описание [ограниченного контекста][BOUNDED-CONTEXT-TERM] `CTX-04` в [замысле продукта][PRODUCT-INTENT-TERM].

Контекст — единственный источник правды о том, кто, сколько, когда и чего потребил. Он превращает факты обращений в потребление в единицах провайдера, атрибутированное внутренним ключам и подразделениям, и хранит эту историю годами. Сверка с провайдером и распределение за отчётный период строятся поверх него в [CTX-05](../CTX-05-settlement-and-allocation/readme.md).

## Единый язык

- **Факт обращения** — неизменяемая запись об одном обращении: внутренний ключ, провайдер, контракт, эндпоинт, время, исход и списанные единицы потребления.
- **Исход обращения** — запрос к провайдеру (с ответом провайдера), ответ из кэша, устаревший ответ из кэша, отказ продукта (по ключу, доступу или лимиту).
- **Тарифицируемый факт** — факт, за который провайдер списывает единицы потребления по своим правилам тарификации.
- **Потребление** — сумма единиц потребления по тарифицируемым фактам за период в выбранном разрезе.
- **Сэкономленные единицы** — единицы, которые были бы списаны, если бы ответы из кэша были запросами к провайдеру.
- **Атрибуция** — отнесение факта к внутреннему ключу и к подразделению, к которому ключ относился в момент обращения.

## Границы

### Входит

- Фиксация факта каждого обращения и его исхода.
- Расчёт единиц потребления по правилам тарификации, действовавшим в момент обращения.
- Атрибуция ключу и подразделению.
- Многолетняя статистика и аналитика потребления.

### Не входит

- Правила тарификации — [CTX-01](../CTX-01-providers-and-contracts/readme.md).
- Решения по лимитам — [CTX-02](../CTX-02-consumers-and-limits/readme.md).
- Закрытие отчётного периода, сверка и отчёт о распределении — [CTX-05](../CTX-05-settlement-and-allocation/readme.md).
- Технические показатели обращений (время ответа, ошибки) для эксплуатации — [CTX-06](../CTX-06-observability/readme.md).

## Capability в этом контексте

Перечень — в [index.md](index.md): `CAP04-01`, `CAP04-02`.

## Интеграция

- Получает факты обращений от [CTX-03](../CTX-03-proxying-and-caching/readme.md).
