# CTX-05: Сверка и распределение

Описание [ограниченного контекста][BOUNDED-CONTEXT-TERM] `CTX-05` в [замысле продукта][PRODUCT-INTENT-TERM].

Контекст работает с отчётными периодами: закрывает период, сверяет потребление по контракту с провайдером и распределяет его по ключам и подразделениям. Он оперирует количествами (единицами потребления); перевод в деньги и бухгалтерские проводки выполняются вне продукта.

## Единый язык

- **Отчётный период** — период, за который организация сверяется с провайдером и распределяет потребление.
- **Закрытие периода** — фиксация итогов потребления за период; после закрытия итоги не меняются, исправления оформляются корректировкой.
- **Акт провайдера** — данные провайдера о потреблении по контракту за период.
- **Сверка** — сопоставление потребления по контракту за период по данным продукта с актом провайдера.
- **Расхождение** — разница между потреблением по данным продукта и по акту провайдера.
- **Распределение потребления** — доли потребления контракта за период по внутренним ключам и подразделениям, в единицах потребления.

## Границы

### Входит

- Закрытие отчётного периода и корректировки закрытых периодов.
- Сверка с провайдером и объяснение расхождений.
- Отчёт о распределении потребления по ключам и подразделениям.

### Не входит

- Подсчёт потребления — [CTX-04](../CTX-04-consumption-metering/readme.md).
- Цены, суммы в деньгах, бухгалтерские проводки — вне продукта.
- Аналитика произвольных периодов — `CAP04-02`.

## Capability в этом контексте

Перечень — в [index.md](index.md): `CAP05-01`, `CAP05-02`.

## Интеграция

- Получает потребление за период от [CTX-04](../CTX-04-consumption-metering/readme.md).
- Получает контракт и его период от [CTX-01](../CTX-01-providers-and-contracts/readme.md), структуру подразделений на период — от [CTX-02](../CTX-02-consumers-and-limits/readme.md).
- Отдаёт отчёты во внешние финансовые системы организации.
